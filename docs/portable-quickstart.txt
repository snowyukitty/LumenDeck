LumenDeck for Windows 10 / 11 (x64)

Get started
1. Extract the entire ZIP into a folder you want to keep.
2. Open LumenDeck.exe. No .NET installation or administrator access is needed.
3. Use Identify to find each screen, select it on the desk map, then
   adjust its supported brightness or warmth. Click a value or press F2 for
   exact entry. Check the requested/observed status after an adjustment.
   Day / Evening / Night use estimated luminance; Custom requests the
   per-monitor levels saved when you adjust a slider.

Open LumenDeck.exe again to reveal the existing window if it is hidden in the
notification area. A second launch does not start another monitor controller.
If it cannot reveal the window, use the existing tray icon or retry once startup
finishes. Normal user permissions are recommended; administrator access is not
required.

The material interface shows one selected display. The map preserves Windows
positions and pixel proportions, not physical screen sizes. Night saver stays
at the top; Desk actions contains global presets and the work-display choice.
Display actions contains blackout/restore, shortcuts, brightness estimates and
Advanced controls. Advanced controls opens the classic panel for advertised
monitor features. Settings > Material interface returns to the material window.
Settings > Classic interface saves the classic panel as your preferred view.
The classic panel retains All displays, spatial map navigation and card reflow.

Keyboard controls
Tab/Shift+Tab moves between controls; Enter/Space activates a focused button.
Ctrl+Page Down/Page Up switches displays. Slider arrows adjust one hardware unit,
or 50 K for warmth; Shift makes ten-unit steps. Home/End selects the endpoints.
F2 or Enter on a slider opens exact entry. Ctrl/Alt blocks slider adjustments.
Press F1 or choose Settings > Keyboard controls for the offline guide, including
classic-only map navigation. Escape closes the guide.

Exact values
Click a slider's number, or focus it and press F2/Enter. The exact editor shows the
display/control, unit and range. Brightness/contrast use hardware units; warmth
accepts Kelvin. Apply sends a request; check the screen and card warnings.
Cancel/Escape discard the draft. Refresh replacing the card or disabling the
control cancels the open entry.

Settings
Settings > Appearance offers Smoke, Frost and Ceramic. Smoke/Frost can request
Mica, Glass or Solid; Ceramic is opaque. Windows high contrast takes priority,
and unsupported material or disabled transparency uses an opaque fallback.
A confirmed save updates appearance without changing displays or Night saver.
The classic panel and shared editors retain Amber, Paper, Ocean and Violet.

The footer reports the active settings save state. Retry settings save retries
the active values; failed preference choices must be selected again. Pending
writes finish before Exit is allowed.
If the file changed outside the window or cannot be loaded, restore active
blackouts and use tray Exit before reopening. Back up damaged settings privately
before repair; retry never overwrites a changed or invalid source automatically.

Use Settings in the window for Windows startup, minimised launch, closing to the
notification area and saved-warmth reapplication. Startup switches stay in sync
with the tray. Local preferences save in the background; checks stay at the active
preference until completion. Local preference options are disabled while saving. An
unconfirmed save retains the previous preference. Start minimised applies at the next launch; with keep-running
off, it starts on the taskbar. Reapply warmth affects the next scan or Refresh,
without adjusting current warmth when you toggle it. An unavailable startup
registration read is labeled explicitly. Use tray Exit to quit if keep-running
is enabled.
If a save is pending, wait for completion and use Exit again. Shortcuts also
activate only after confirmed storage; a saved shortcut can still fail Windows
registration. A pending save prevents starting a new blackout; retry afterwards.

If settings changed outside the app, quit and reopen before saving again. A busy
writer can be retried when it finishes. A damaged/unreadable settings file is
preserved while the app uses session defaults. Do not delete it while screens
are blanked: it may contain their saved brightness for recovery. Restore screens
and exit normally before backing up and repairing or resetting the file.
CLI exit code 2 also reports an unconfirmed settings save; monitor requests may
already have been applied, so inspect their state before repeating a command.

If a control is unavailable, open Connection help. External monitors may need
DDC/CI enabled in their own menu. If no cards appear, the window distinguishes
reading displays, a completed scan with none found and a failed scan. Connection
help stays available while reading; use Refresh after checking the connection.
Refresh may reapply saved warmth and recover active blackouts. Opening help does
not start another scan.

Built-in panels use Windows brightness support.
Some docks and KVMs block control commands; not all panels expose contrast.

Brightness estimates
Display actions > Brightness estimate lets you set peak/floor luminance and sources.
Its preview calculates estimated nits and preset brightness percentages. Save
changes estimates and future presets; it does not adjust the screen immediately.
Identical model names share a profile. Endpoint measurement is your declaration,
not app verification. Existing files are backed up in the settings directory's
profile-backups folder. If the file changed during editing, cancel and reopen.

Night saver
Use Night saver in the toolbar. It keeps the primary display on by default;
choose another under Desk actions > Keep dimmed during Night saver. The work display requests
5% of its hardware brightness range, rounded down, only if initially brighter.
This is independent of the Night reading preset; actual darkness depends on the
panel's minimum brightness. Unsupported work displays stay unchanged. Other displays
become black. End Night saver returns the saved brightness, including the
work display, unless you chose a newer brightness for it. Individual Blank screen actions
remain separate. Automatic presets skip the dimmed work display. Night saver does
not put Windows to sleep. Individual blackouts also restore by clicking their
overlay. This is a reversible blackout, not
hardware power-off. Exit normally from the tray menu before moving or replacing
the app files so active blackouts can be restored.

Command line
Open a terminal in the extracted folder:
  .\lumendeck-cli.exe --help
  .\lumendeck-cli.exe --support-report
  .\lumendeck-cli.exe --preset Night
  .\lumendeck-cli.exe --preset Custom

Support
Settings > About LumenDeck > Copy version copies the running GUI version and
build for an issue. Only that explicit action writes these two lines to the
clipboard; opening About does not copy anything.
Connection help > View support report shows a minimal report you can review and
copy into an issue. Names, serials, device identifiers, paths and raw logs are
excluded; counts and control ranges still describe your setup. Nothing is
uploaded automatically. Advanced --diagnose output includes identifiers.
Project and issues: https://github.com/snowyukitty/LumenDeck

Settings are stored in %APPDATA%\LumenDeck, separately from these executables.
Moving or deleting this folder does not erase settings. Portable describes how
the app binaries are distributed, not where the app stores settings.

Integrity
SHA256SUMS.txt records hashes of the package files. Check the ZIP hash against
the separate .sha256 file supplied with a release when available. Hashes detect
file changes; they do not prove who created the package. This package is not
code-signed. If Windows blocks a download, verify its source before running it.
