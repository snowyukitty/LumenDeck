# Code of conduct

Be decent. Assume the other person is trying to help.

Concretely: no harassment, no personal attacks, no dismissiveness toward people
reporting problems with hardware you do not own. Monitor firmware is strange and
inconsistent — a report that sounds impossible is usually a real monitor
behaving badly, not a user mistake.

Report a problem by opening a private security advisory or emailing the
repository owner via their GitHub profile. Maintainers may remove comments or
block accounts that make the project unpleasant to participate in.
